# Omkar Automotive Portfolio

Open `index.html` in a browser. The website works locally without a framework.

Files:
- index.html
- style.css
- script.js

Before using it on a CV:
1. Replace the email address.
2. Replace GitHub and LinkedIn links with your profiles.
3. Add your real resume link.
4. Replace the YOUR PHOTO placeholder with your own photo if desired.
5. Only keep project claims you can explain in an interview.
6. Add your real GitHub repositories/live demos when ready.

The car cards use CSS artwork so the site works immediately without requiring copyrighted car images.
